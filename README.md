# 🎒 GEPT Kids 英文單字練習 APP

專為小學英檢 (GEPT Kids) 設計的互動式單字練習網頁 APP。

## ✨ 特色功能

- **149 個英檢核心單字**：涵蓋動物、食物飲料、服飾配件、顏色、家庭親屬、自然風景、健康感受、購物生活等各大主題。
- **四大練習模式**：
  - 🃏 **單字卡 (Flashcards)**：支援雙向翻轉記憶、真人朗讀、隨機抽卡。
  - ✅ **選擇題 (Quiz)**：四選一即時反饋，測驗完畢可立即針對本次錯題加強特訓。
  - ⌨️ **拼字練習 (Typing)**：互動拼寫挑戰，支援單字發音與字元提示。
  - ❌ **錯題本 (Mistakes Hub)**：自動記錄做錯的單字，提供專屬「錯題特訓模式」，攻克記憶弱點。
- **🔊 真人語音發音**：內建 Web Speech API，支援標準美式英語單字朗讀。
- **💾 本地進度保存**：所有答題記錄與錯題本皆保存於瀏覽器 localStorage，重新開啟進度不遺失。
- **🌐 零依賴 & GitHub Pages 即開即用**：單一檔案，無外部套件依賴，支援手機與電腦瀏覽。

## 🚀 如何使用

1. 直接在瀏覽器中開啟 index.html。
2. 或啟用 GitHub Pages：在儲存庫 Settings -> Pages 將 Branch 設為 main，即可透過 GitHub Pages 線上練習！
